04

How It Works

서비스 경로 밖에서 동작하는 소프트웨어 오버레이

PeerGFS는 NAS마다 Agent 서버를 두고 복제를 수행합니다. 사용자와 애플리케이션이 NAS에 접근하는 경로에는 개입하지 않으므로, 복제 소프트웨어에 문제가 생겨도 NAS 서비스 중단으로 이어지지 않습니다.

구성 요소

Peer Agent

NAS와 연결된 전용 서버(Windows 또는 Linux)에 설치합니다. NAS의 파일 변경 이벤트를 받아 변경 내용을 보냅니다.

Peer Management Center (PMC)

모든 Agent와 복제 작업을 구성하고 감시하는 중앙 관리 서버입니다.

Peer Management Broker

PMC와 Agent 사이의 통신을 중계하는 메시징 서버입니다. 기본적으로 PMC와 같은 서버에 함께 설치되며, 규모에 따라 여러 대로 나눠 둘 수 있습니다.

복제 흐름

  1. 01

    파일 변경

    WAS 또는 사용자가 NAS에 파일을 씁니다.

  2. 02

    이벤트 감지

    NAS가 변경 이벤트를 Agent에 알립니다.

  3. 03

    변경분 추출

    파일 전체가 아니라 변경된 블록을 가려냅니다.

  4. 04

    전송

    TLS로 암호화하여 상대 센터의 Agent로 보냅니다.

  5. 05

    반영과 검증

    상대 센터 NAS에 반영하고 체크섬으로 무결성을 검증합니다.

The Difference

LeadingPoint Active-Active NAS DR의 차별점은 스토리지 내부의 복제 기능이 아니라, 스토리지 바깥에서 NAS와 NAS를 잇는 동기화 계층에 있습니다.

스토리지 내장 복제는 같은 벤더 제품 사이에서만 동작하고 DR 센터를 대기 상태로 둡니다. PeerGFS는 벤더와 관계없이 양쪽 NAS를 모두 운영 상태로 유지하고, 장애 복귀·파일 충돌·랜섬웨어 같은 운영 상황까지 함께 다룹니다.

02 이벤트 기반 변경 감지 NAS의 파일 변경 이벤트를 받아, 복제 주기를 기다리지 않고 즉시 복제를 시작합니다.

07 정합성 안전망 충돌 파일은 격리하고, 삭제·덮어쓸 파일은 먼저 보관해 되돌릴 수 있게 합니다.

FAQ

자주 묻는 질문

Q01기존 NAS를 교체해야 합니까?

아닙니다. 운영 중인 NAS를 그대로 사용하고 Agent 서버와 관리 서버만 추가합니다. 마운트 경로도 바꾸지 않습니다.

Q02주 센터와 DR 센터의 NAS가 서로 다른 벤더 제품이어도 됩니까?

네. 지원 목록 안의 스토리지라면 벤더가 달라도 하나의 복제 환경으로 구성합니다.

Q03어떤 서버가 추가로 필요합니까?

NAS마다 Agent 서버가 필요하고, 전체에 관리 서버(PMC)가 하나 필요합니다. Broker는 기본적으로 관리 서버에 함께 설치됩니다. SMB 데이터는 Windows Agent가, NFS 데이터는 Linux Agent가 담당하므로 두 종류의 데이터가 모두 있으면 Agent 서버도 종류별로 둡니다.

Q04NFS 환경에서도 Active-Active로 구성할 수 있습니까?

네. NFS 환경은 양쪽 센터의 변경을 실시간으로 동기화하는 방식으로 구성합니다. 분산 파일 잠금은 SMB 환경의 기능이므로, NFS에서 같은 파일을 양쪽 센터가 동시에 수정하는 업무는 애플리케이션 설계에서 조정해야 합니다. 첨부파일 업로드나 읽기 위주의 공유 데이터에는 그대로 적용할 수 있습니다.

Q05한쪽 센터에 장애가 나면 복제는 어떻게 됩니까?

복제는 대기 상태가 되고, 남은 센터의 NAS는 계속 서비스합니다. 장애 센터가 복귀하면 자동으로 전체 재스캔을 수행해 양쪽을 맞춘 뒤 양방향 복제로 돌아갑니다.

Q06양쪽 센터에서 같은 파일을 동시에 고치면 어떻게 됩니까?

SMB 환경에서는 분산 파일 잠금이 동시 수정을 막습니다. 잠금이 적용되지 않는 환경에서 충돌이 생기면 최종 수정 시각을 기준으로 자동 해결합니다. 자동으로 해결되지 않는 파일은 어느 버전도 삭제하지 않고 격리해서 관리자가 고르도록 합니다.

Q07RPO는 얼마입니까?

파일이 변경되는 즉시 복제가 시작되므로 RPO는 Near-Zero입니다. 도입 전에 고객 환경에서 복제 지연을 검증합니다.

Q08센터 사이의 거리에 제한이 있습니까?

비동기 방식이므로 거리 제약은 없습니다. 다만 회선 대역폭이 일 변경량을 감당할 수 있어야 합니다.

Q09센터 간 전송 구간은 암호화됩니까?

네. 기본적으로 TLS로 암호화하며, 기관의 인증서로 교체할 수 있습니다.

Q10랜섬웨어에 감염되면 DR 센터로도 퍼지지 않습니까?

악성 이벤트 탐지(MED)가 이상 행동을 감지하면 알림을 보내고, 설정에 따라 해당 서버를 복제에서 분리합니다. 확산을 최소화하는 기능이며, 백업과 함께 운영하는 것을 권장합니다.
